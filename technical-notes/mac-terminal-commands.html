Mac Terminal Commands

Quick command tables for directory navigation, listing contents, file operations, and help.

Change Directory

Move around the filesystem quickly

CommandDescriptionExample
cdGo to your home directory.cd
cd ~Go to home using explicit shortcut.cd ~
cd /Go to the filesystem root.cd /
cd ..Move up one directory level.cd ..
cd ../..Move up two directory levels.cd ../..
cd -Switch back to the previous directory.cd -
cd [folder]Change into a specific directory.cd Documents
pwdPrint current working directory path.pwd

List Directory Contents

Inspect files, metadata, and sort order

CommandDescriptionExample
lsList files and folders in the current directory.ls
ls -aInclude hidden files (dotfiles).ls -a
ls -laDetailed list including hidden files.ls -la
ls -lLong format with permissions, owner, size, and date.ls -l
ls -lhLong format with human-readable file sizes.ls -lh
ls -ltSort by modification time (newest first).ls -lt
ls -SSort by file size (largest first).ls -S
ls -FAppend type markers like / for directories.ls -F
ls -1Show one entry per line.ls -1
ls -CShow output in multi-column format.ls -C
ls -l /Detailed listing of root directory contents.ls -l /
ls -loShow long output with file flags on macOS.ls -lo

File and Directory Management

Create, copy, move, and delete safely

CommandDescriptionExample
mkdir [dir]Create a directory.mkdir Projects
mkdir -p [path]Create nested directories in one command.mkdir -p Work/2026/Reports
mkdir "[dir with spaces]"Create a directory with spaces in its name.mkdir "My New Folder"
rmdir [dir]Remove an empty directory.rmdir EmptyFolder
rm -R [dir]Remove a directory and all contents recursively.rm -R OldProject
touch [file]Create an empty file (or update modified time).touch notes.txt
cp [file] [dir]Copy a file to another directory.cp draft.txt ~/Documents/
cp -i [file] [dir]Copy with overwrite confirmation prompt.cp -i report.txt ~/Backup/
cp -R [src_dir] [dest_dir]Copy an entire directory recursively.cp -R app "app-backup"
ditto -V [src] [dest]Copy folders with verbose progress on macOS.ditto -V ~/A ~/B
mv [file] [new_name]Rename a file or move it in the same directory.mv old.txt new.txt
mv [file] [dir]Move file to another directory.mv image.png ~/Pictures/
mv -i [file] [dir]Move with overwrite confirmation prompt.mv -i data.csv ~/Archive/
mv *.png [dir]Move all matching files using wildcard.mv *.png ~/Pictures/
rm [file]Delete a file permanently.rm temp.txt
rm -i [file]Delete a file with confirmation prompt.rm -i old.txt
rm -f [file]Force delete without confirmation.rm -f cache.tmp
rm [file1] [file2] ...Delete multiple files in one command.rm a.txt b.txt c.txt

HELP Commands

Discover options and command documentation

CommandDescriptionExample
[command] -hShow short help output for many commands.ls -h
[command] --helpShow detailed help/options where supported.mkdir --help
man [command]Open the manual page for a command.man ls
whatis [command]Show one-line description from man database.whatis ls
apropos [keyword]Search man page descriptions by keyword.apropos copy
which [command]Show executable path used in your shell.which git
type [command]Show if target is binary, alias, function, or builtin.type cd
resetReset terminal display/session state.reset

Reference adapted from GeeksforGeeks: Complete Mac Terminal Commands Cheat Sheet (updated July 15, 2025).
