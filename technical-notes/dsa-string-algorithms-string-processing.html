Learning Flow

When strings stop being brute force

1. Check whether repeated comparison exists

If yes, preprocessing is probably useful.

2. Check whether order is symmetrical

Palindrome problems usually exploit center or mirrored structure.

3. Move to multi-pattern indexing

Use tries or suffix-based structures when the query count is large.
