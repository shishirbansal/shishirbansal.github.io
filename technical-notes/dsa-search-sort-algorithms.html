Learning Flow

Useful decision path

1. Check sortedness

If the data is sorted, binary search or two pointers should come to mind immediately.

2. Choose stable or unstable ordering

Merge sort is predictable. Quick sort is fast on average. Heaps fit priority use cases.

3. Reduce scans with pointer movement

Two pointers often replace nested loops when order or target constraints exist.
