Learning Flow

A reliable DP workflow

1. Define the smallest complete state

The state must be enough to continue solving without hidden information.

2. Write recurrence before coding

If the transition is fuzzy, the code will be wrong even if syntax is fine.

3. Optimize only after correctness

Space compression comes after the full table version is already trusted.
