Greedy & Windows - Optimization Techniques

This section is about making local decisions fast: sometimes by taking the best current choice, sometimes by maintaining a moving window.

Concept Map

Optimization toolkit

Subtopics

Techniques from the board

Greedy Algorithms

Activity selection, fractional knapsack, job scheduling, Huffman coding, interval decisions.

Sliding Window

Fixed-size and variable-size windows, longest or shortest valid subarray, frequency tracking.

Monotonic Stack

Next greater or smaller element, largest rectangle, rainwater trapping, stock span style problems.

Monotonic Queue

Sliding window maximum and minimum using a deque that preserves useful candidates.

Learning Flow

How to choose the technique

1. Ask whether local best choices stay valid

If yes, a greedy proof may exist.

2. Ask whether a contiguous range moves gradually

If yes, sliding window can remove repeated work.

3. Ask whether old elements become useless forever

If yes, monotonic stack or queue is often the right abstraction.
