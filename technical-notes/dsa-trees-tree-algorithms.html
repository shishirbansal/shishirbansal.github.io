Learning Flow

Order that reduces confusion

1. Draw the tree and choose traversal

Most tree bugs come from the wrong visit order.

2. Track what each recursive call returns

Height, validity, path info, or aggregate values should be explicit.

3. Move to specialized trees

Use tries for prefixes and indexed trees for range queries or updates.
